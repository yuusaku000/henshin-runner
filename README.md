# へんしんランナー

子供向けの、かんたんなランゲームです。ブラウザで遊べます。

## あそびかた

- 「あそぶ」ボタンを押すか、スペースキー・エンターキーでスタート
- **スペース** か **エンター** でジャンプ（画面をクリックしてもジャンプできます）
- 穴と敵をジャンプでよけながら走ります
- 100m 走るごとに、キャラクターが「へんしん」します
- 穴に落ちたり敵に当たったりしても、すぐ手前から走りなおせます（3秒間むてき）
- ページを読みこみなおす（F5）と、最初からになります

## 遊びやすさの調整

`game.js` のいちばん上にある数字を変えると、速さ・ジャンプの高さ・へんしんする距離などを変えられます。
